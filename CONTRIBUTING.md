# Contributing

Useful improvements and clear bug reports are welcome.

1. Open an issue describing the planning problem or defect.
2. Create a focused branch such as `feat/csv-export` or `fix/zero-capacity`.
3. Keep calculations in `src/core.js` and add or update tests in `tests/`.
4. Run `npm test` and complete the relevant checks in `TESTING.md`.
5. Open a pull request explaining the problem, decision, and test evidence.

Use concise commit messages that describe an outcome, for example `Clarify overloaded team totals`. Avoid unrelated changes in the same pull request.
